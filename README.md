# GlobeTrotter 🌍

**GlobeTrotter** is a personalized travel planning application designed to make multi-city trip planning simple, organized, and interactive.

Users can create and manage trips, discover cities and activities, build day-by-day itineraries, track estimated expenses, visualize their journey through calendars and timelines, and share their travel plans with others.

### Key Features

* 🗺️ Create customized multi-city trips
* 📅 Plan travel dates and day-by-day itineraries
* 🔎 Discover cities and activities
* 💰 Track trip budgets and estimated expenses
* 📊 View cost breakdowns and budget insights
* 🗓️ Visualize trips with calendar/timeline views
* 🔗 Share and copy itineraries
* 👤 Manage user profiles and travel preferences

GlobeTrotter combines **trip management, destination discovery, itinerary planning, and budget tracking** into a single platform, providing an end-to-end solution for personalized travel planning.
